# CEA-ORGANIZADOR

Plugin de Moodle (`tool_ceaorganizador`) del Centro de Innovación Pedagógica y Educación Digital (CEA), USB Cali. Permite organizar el árbol de categorías y cursos de un sitio: mover, ordenar automáticamente, renombrar por lotes y deshacer. Aparece en *Administración del sitio › Cursos*. Requiere Moodle 4.2 o superior.

Instalación: ver [INSTALACION.md](INSTALACION.md). Guía para desarrollo: [CLAUDE.md](CLAUDE.md).

## Desarrollo

```bash
npm install
npm test               # pruebas JS
npm run check-strings  # cadenas de idioma
npm run build          # compila amd/build
npm run package        # dist/CEA-ORGANIZADOR.zip
```
